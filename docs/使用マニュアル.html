TomoniGate ／ 右腕AI 月次成果レポート機能

使用マニュアル（月次成果レポートジェネレーター）

対象：試作品（POC）レビュー用　/　2026年9月時点

本ドキュメントは、右腕AIの追加モジュール「月次成果レポート」試作品（POC）の使い方と、 現時点での設計上の制約をご説明するものです。実際の右腕AIで想定している機能の一部を、 現段階では手入力によるシミュレーションで再現しています。

1. ジェネレーターの構成

このジェネレーターは「入力画面」と「出力画面」の2画面で構成されるシンプルな一往復のツールです。

入力画面
①会社名・対象年月・来月の優先課題（手入力）
→
入力画面
②過去の決定／今月の対話／KPI／価値観（本来は右腕AIの過去ログデータベースから自動連携される想定のデータ）
→
出力画面
AIが生成する月次成果レポート（Claude Opus 5による自動生成・ストリーミング表示）

※ ①の「会社名・代表者名」は、PoC版ではシミュレーションのため自由入力ではなく、 「株式会社サンプル」「テスト株式会社」の2択から選ぶプルダウン形式にしています。

入力データの2つの性質

入力画面のデータは、性質の異なる2種類に分かれています。

区分 項目 本来の位置づけ
① 手入力する情報 基本情報（会社名・対象年月・来月の優先課題） 都度ユーザーが入力する項目。今後も手入力のまま
② 自動連携される想定の情報 過去ログDB: past_decisions 過去ログDB: dialogues 過去ログDB: kpis 過去ログDB: values_ltm 経営ダッシュボード・共創機能・LTMが右腕AIの過去ログデータベースに書き込んだデータを、本来は自動で読み込む想定
PoC版とβ版以降の違い：
PoC版では、②の4項目もあらかじめダミー値が自動入力された状態で画面に表示されており、 実際にユーザーに入力していただくのは①の基本情報だけです（②は「見えているが、確認・修正できる」状態）。 β版以降では、②はこの入力画面のUI自体から姿を消し、システムが右腕AIの過去ログデータベースから 自動取得した上でレポート生成に活用する想定です。つまり将来的には、ユーザーは①を入力するだけで レポートが作成される形になります。

2. あくまで「シミュレーション」である点について

重要：実際のデータベースには接続していません

画面上に「右腕AIの過去ログデータベース」という表記がありますが、これは 「本番ではここが自動連携される」ことを示す説明ラベルにすぎず、実際にそうしたデータベースへ 接続しているわけではありません。現状は、あらかじめ用意した架空企業のダミーデータを アプリのソースコード内に直接書き込み、画面を開いた時にその内容が初期値として 表示される形でシミュレーションしています。

技術的には、2026年4月〜8月のシミュレーションデータは、アプリのソースコード内 lib/sampleData.ts にハードコードされたTypeScriptの配列 （SAMPLE_PAST_DECISIONS など）として格納されています。 ページを開いた時にこの静的データがフォームの初期値として読み込まれる仕組みであり、 実データベースには一切接続していません。

このシミュレーション用データは、ある架空の中小企業（受託製造業を想定）が 2026年4月〜8月の間に経験した「値上げ対応」「大口案件と既存顧客対応の両立」 「新卒スタッフの教育」などの一連の出来事として、一つのストーリーになるように作成しています。

このため、対象年月の選択肢は現時点では 2026年7月度・8月度の2つのみ に絞っています。実際の運用時には全ての月が選択可能になる想定ですが、 現在のPOCではダミーデータの範囲でしか正しく成果を判断できないため、意図的に制限しています。

3. 「過去3ヶ月分」を参照する設計とデータ範囲

月次成果レポートは、対象月の成果だけを単独で見るのではなく、 それ以前の意思決定が積み重なった結果として成果を捉える設計になっています。 そのため、レポート生成時には対象月から遡って直近3ヶ月分の「過去の決定」データを参照します。

例）2026年8月度のレポートを作る場合 → 2026年7月・6月・5月の「過去の決定」を参照
　　2026年7月度のレポートを作る場合 → 2026年6月・5月・4月の「過去の決定」を参照

この参照期間をまかなうため、シミュレーション用データベースには2026年4月〜8月の5ヶ月分を用意しています。

※ 7月度レポートを選ぶと4〜6月が参照期間、8月度レポートを選ぶと5〜7月が参照期間になります。 4月分のデータは7月度レポートのためだけに用意しています。

本番実装時の想定について：
今回のPOCでは検証のしやすさを優先し、参照期間を「直近3ヶ月」に固定しています。 しかし、実際に右腕AIの過去ログデータベースや「社長の右腕AI」 システムに実装する際には、右腕AI本体が持つ過去ログデータベースから該当データを取得する想定であり、 参照期間も3ヶ月に限定する必要はありません。例えば過去1年分を遡って当月の成果を 評価する、といった設計も想定しています（1年間という期間が適切かどうかは、今後 あらためて検討する論点です）。

4. あわせてご確認いただきたい点

  • 入力画面の下部にある「過去の決定」「今月の対話」の日付と、選択した対象年月が食い違っている場合、 レポート生成前に赤系（ボルドー色）の警告メッセージで具体的に指摘する仕組みを入れています。 これは、本来右腕AIの過去ログデータベースで自動的に整合するはずのデータを手入力で再現している以上、 入力ミスによる事実と異なるレポート生成を防ぐための安全策です。
  • 「今月の対話」のサンプルデータは2026年8月度を主な想定として作成しているため、 対象年月を7月度に切り替えて試される場合は、上記の警告が表示されることがあります。 その場合は上記3.の整合性チェック機能の動作としてご確認いただくか、 日付をお好みの検証用の値に書き換えてからお試しください。
